## 一、产品理解

### 1.1 产品定位

**全球旅游信息服务平台**

核心差异化：
- 平台筛选维护内容 → 精准度
- 实时信息更新 → 时效性
- 多语言覆盖 → 无障碍
- 文化深度解读 → 体验升级

### 1.2 目标用户

| 用户类型 | 需求 |
|----------|------|
| 中国出境游客 | 日韩泰新马5大目的地，信息无语言障碍 |
| 入境游客 | 多语言浏览中国景点信息 |
| 全球用户 | 真正的多语言全球化体验 |

### 1.3 MVP核心功能

| 功能模块 | 功能点 | 优先级 |
|----------|--------|--------|
| 信息展示 | 景点/交通/文化基础信息 | P0 |
| 搜索 | 关键词+基础筛选 | P0 |
| 多语言 | 中/英/日/韩/泰5种语言 | P0 |
| 内容质量 | 平台筛选机制 | P0 |

## 二、设计愿景

### 2.1 设计理念

**"无界探索，沉浸旅程"**

finger-more 的设计应该让用户感受到：
- **无障碍**：语言不是障碍，内容无界流通
- **可信赖**：平台筛选，信息精准可查
- **沉浸感**：文化深度，让旅行更有意义

### 2.2 设计关键词

| 关键词 | 说明 |
|--------|------|
| 轻盈 | 界面简洁，信息层级清晰，不压迫 |
| 信赖 | 专业感，平台背书，质量保障 |
| 沉浸 | 文化深度，故事化呈现 |
| 无界 | 多语言，跨文化，全球一致性 |

## 三、视觉设计方向

### 3.1 设计风格

**iOS 26 Liquid Glass × 全球旅行美学**

融合：
- Apple 最新的 Liquid Glass 设计语言（毛玻璃、层次感、光泽）
- 旅行/地图元素（地理位置、路线、文化符号）
- 无障碍设计（WCAG 2.2 AA +）

### 3.2 色彩方向

**方案A：自然灵感色**

| 用途 | 色相 | 说明 |
|------|------|------|
| 主色 | 蓝色系 | 天空、海洋、信任感 |
| 辅色 | 暖橙/日落色 | 温暖、探索、旅程 |
| 强调色 | 翠绿 | 自然、文化、深度 |
| 背景 | 浅沙/米白 | 轻盈、干净 |
| 深色模式 | 深蓝/墨灰 | 沉浸、专注 |

**方案B：现代简约色**

| 用途 | 色相 | 说明 |
|------|------|------|
| 主色 | 品牌蓝 | 统一品牌识别 |
| 辅色 | 渐变紫蓝 | 科技感、现代 |
| 强调色 | 明黄 | 重要信息、CTA |
| 背景 | 纯白/深灰 | 极简主义 |

**推荐方案A**：自然灵感色更符合旅行产品调性，情感连接更强。

### 3.3 字体方向

| 用途 | 字体选择 |
|------|----------|
| 标题/品牌 | 无衬线体，中英文均有优秀表现 |
| 正文 | 系统默认/Google Fonts，等宽支持多语言 |
| 数字/数据 | Tabular figures，保证对齐 |

**多语言支持重点：**
- CJK（中日韩）：Noto Sans CJK / Source Han Sans
- 拉丁语系：SF Pro / Inter
- 泰语：Noto Sans Thai

### 3.4 图标方向

**SF Symbols 7（iOS） + Material Symbols（Android） + Lucide（Web）**

核心图标库：
- 导航类：搜索、筛选、收藏、分享
- 地点类：景点、交通、餐饮、住宿
- 操作类：语言切换、放大缩小、播放音频
- 状态类：已验证、实时更新、AI推荐

### 3.5 布局节奏

| 页面类型 | 布局风格 |
|----------|----------|
| 首页/发现 | 大图卡片流，视觉冲击 |
| 详情页 | 左图右文/上图文下，信息密度适中 |
| 搜索结果 | 列表+地图切换，效率优先 |
| 个人中心 | 简洁列表，功能导向 |

### 3.6 动效方向

| 场景 | 动效风格 |
|------|----------|
| 页面切换 | 滑动过渡，流畅自然 |
| 内容加载 | 骨架屏 + 微光效果 |
| 交互反馈 | 轻触即反馈，按压缩放 |
| 沉浸体验 | 慢速缓动，优雅呈现 |
| 语言切换 | 渐变过渡，无跳跃感 |

**偏好设置：**
- `prefers-reduced-motion` 必须支持
- 120Hz ProMotion 适配

## 四、交互设计方向

### 4.1 核心交互模式

| 功能 | 交互模式 |
|------|----------|
| 浏览景点 | 大图预览 → 点击展开详情 |
| 搜索 | 实时搜索 + 筛选器 |
| 地图浏览 | 地图+列表双视图切换 |
| 多语言 | 一键切换，记忆偏好 |
| 收藏 | 长按/点击收藏，夹到收藏夹 |

### 4.2 手势支持

| 手势 | 功能 |
|------|------|
| 点击 | 选择/确认 |
| 长按 | 预览/更多操作 |
| 双指缩放 | 地图/图片缩放 |
| 左右滑动 | 切换语言/浏览下一个 |
| 下拉刷新 | 更新内容 |

### 4.3 导航结构

```
底部TabBar（4个）：
├── 发现（首页/推荐）
├── 搜索（搜索+筛选）
├── 收藏（我的收藏）
└── 我的（个人中心）

顶部导航栏：
├── 左侧：返回/菜单
├── 中间：页面标题（支持语言切换入口）
└── 右侧：更多操作
```

### 4.4 空状态设计

| 场景 | 空状态设计 |
|------|------------|
| 搜索无结果 | 插画 + "换个关键词试试" + 热门推荐 |
| 收藏为空 | 插画 + "发现喜欢的收藏起来" + 推荐景点 |
| 网络错误 | 插画 + "网络开小差" + 重试按钮 |

## 五、无障碍设计方向

### 5.1 基础无障碍

| 要求 | 标准 |
|------|------|
| 对比度 | WCAG 2.2 AA（主文字 ≥ 4.5:1，次级文字 ≥ 3:1） |
| 触控目标 | ≥ 48×48px |
| 焦点指示器 | 可见键盘/蓝牙焦点 |
| 替代文本 | 图片/图标必须有替代文本 |

### 5.2 多语言无障碍

| 要求 | 说明 |
|------|------|
| 语言切换 | 界面语言可切换 |
| 文本方向 | 支持LTR/RTL |
| 字号缩放 | 支持Dynamic Type/字体大小调整 |

### 5.3 特殊用户支持

| 用户群体 | 支持方案 |
|----------|----------|
| 视障用户 | 屏幕阅读器完整支持 |
| 运动障碍 | 键盘导航 + 语音控制 |
| 认知障碍 | 简单清晰的界面 |
