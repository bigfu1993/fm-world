# Geo 数据层级检查

检查日期：2026-06-23；最近更新：2026-06-24

检查范围：`front-end/src/db/geo`

目标层级：

```text
洲
  国家
    省/州/省级行政区
      市/县/区/郡等末级行政区
```

本次以 `AS/CN` 的维护方式为参考：`CN` 下是省级节点，例如 `CN-11`；省级节点下再维护市县区节点，例如 `CN-11-0101`。目录结构上，父级节点使用目录和 `index.ts`，其下一级数据使用当前目录内的独立 `.ts` 文件，例如 `CN-15/index.ts` 引用 `CN-15/CN-15-07.ts`。

本轮口径修正：本报告要排查的是“实际属于国家下二级行政地区，却维护在国家直下一级”的数据，不再把中文名称中带 `市 / 县 / 郡 / 自治市 / 镇` 的节点直接判定为错误。很多国家的一级行政区本来就叫“县、郡、自治市、广域市、城市州”等。

## 口径修正后的结论

- 当前全量树包含 6 个洲、193 个国家、3334 个国家直下子级节点、4584 个第四层节点。
- 除 `CN` 外，`AD`、`AM`、`AZ`、`GB`、`LI`、`LV`、`MD`、`ME`、`MK`、`MT`、`SI`、`SM`、`UG` 和 `US` 已具备第四层结构：`GB -> GB-构成国 -> 地方行政区`，`US -> US-州 -> US-州-县`，其余已处理国家均为 `国家 -> 国家编码-00 -> 待考证旧区划`。
- 除 `CN` 外，当前已不存在国家直下同时有“带子级节点”和“无子级节点”的混合结构。
- 按“真实行政层级误挂”口径，`GB` 和 `AZ-NX` 已处理；剩余优先看 `BA`，再条件复核 `PH`、`RS`。
- `JP / KR / VN / RO / IE / HR / EE / MW / CV / TL / BN / NO / TT` 等国家虽然名称命中“县、郡、市、自治市”，但更可能是一级行政区或省级等价单位，不应自动下沉。
- `BD / CZ / NP / AE / MY` 更偏向翻译、数据版本或非行政边界问题，和“二级行政区误挂一级”不是同一类问题；`AD / AM / AZ / LI / LV / MD / ME / MK / MT / SI / SM / UG` 已按“数据来源待考证”兜底规则迁入 `国家编码-00` 伪一级。

## 不是层级误挂的典型名称命中

这些国家容易被中文后缀误报，但从层级语义看不应自动移动：

| 国家 | 命中原因 | 判断 |
| --- | --- | --- |
| `JP` 日本 | 大量节点叫“县”，另有“府/都/道” | 日本都道府县是国家一级省级行政区，不能按“县”字下沉 |

| `RO / IE / HR / EE / LT / LR / MW / TL / CV / BN / NO / TT` | 县名、郡名、自治市名较多 | 这些国家的县/郡/自治市多是国家一级行政区或一级地方单位 |

## 后续处理建议

- `AZ` 已按伪一级兜底迁入 `AZ-00`；剩余缺失边界和非标准 `AZ-X01~` 需要单独定处理口径。
- 对于数据来源待考证但需要先统一四层结构的国家，采用 `国家编码-00` 伪一级规则：名称为 `*+国家名称`，geo 数据复用国家数据，所有待考证国家直下旧节点迁入该伪一级下。
- `BA / PH / RS` 不建议直接批量移动，先补一份国家层级映射表，明确每个国家采用哪个行政父层。
- 给 `GeoNode` 或旁路配置增加 `geoLevel` / `adminLevel` 元数据，例如 `continent / country / province / cityCounty / nonAdmin`，避免后续继续靠中文名称判断层级。
- 翻译问题、版本问题与层级问题分开处理：`AD / AM / AZ / BD / CZ / LI / LV / MD / ME / MK / MT / NP / SM / UG / AE / MY` 中的缺失代码、旧代码、名称问题优先建“名称修正/数据版本”任务，不和层级迁移混在一起；已按伪一级兜底的国家仍需要保留后续真实数据迁移任务。
- 若产品层级必须统一为四层，建议逐国补父层数据；若短期只展示三级，业务文案应使用“地区/行政区”而不是固定写“省”。

## 外部口径参考

- [ISO 3166-2:GB](https://en.wikipedia.org/wiki/ISO_3166-2%3AGB)：英国同时包含构成国/省以及地方政府、区、郡、市镇等代码，说明处理前 `GB` 直下节点混入了更细层级。
- [ISO 3166-2:AZ](https://en.wikipedia.org/wiki/ISO_3166-2%3AAZ)：阿塞拜疆包含 `AZ-NX` 自治共和国，以及 municipalities/rayons；其中部分 Nakhchivan 下属 rayon 标注了 parent subdivision `NX`。
- [Administrative divisions of the Philippines](https://en.wikipedia.org/wiki/Administrative_divisions_of_the_Philippines)：菲律宾常见层级为 regions、provinces/independent cities、cities/municipalities、barangays。
- [Administrative divisions of Serbia](https://en.wikipedia.org/wiki/Administrative_divisions_of_Serbia)：塞尔维亚需区分自治省/城市/市镇等政治层级与 administrative districts。
- [Confederal entities of Bosnia and Herzegovina](https://en.wikipedia.org/wiki/Confederal_entities_of_Bosnia_and_Herzegovina)：波黑包含 Federation、Republika Srpska、Brcko District 等上级结构，当前数据需要人工确认真实父层。
- [Municipalities of North Macedonia](https://en.wikipedia.org/wiki/Municipalities_of_North_Macedonia)：北马其顿 municipalities 是国家一级行政区。
- [ISO 3166-2:MK](https://en.wikipedia.org/wiki/ISO_3166-2%3AMK)：当前北马其顿 ISO 代码定义为 80 个 municipality，且 2020-03-02 起大量旧两位代码迁移为三位代码。
