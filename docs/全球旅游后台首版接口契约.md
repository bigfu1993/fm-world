# finger-more 全球旅游后台首版接口契约

本文承接开发规格第 05 节，定义管理接口、公开读取和错误响应。两类接口的消费契约在前端开发前确定。管理接口由管理后台服务端交付，旅客公开接口由客户端服务交付。字段归属、授权会话和用户端消费见开发规格。 [首版开发规格](全球旅游后台首版开发规格.md) · [实施顺序](全球旅游后台首版实施方案.md#09-实施顺序与完成门槛)

首版统一使用 `/api` 前缀。JSON 成功体直接返回资源或回执。`GET` 和 `PATCH` 成功用 `200`，`POST` 创建记录用 `201`，`DELETE` 成功用 `204`。重放幂等请求使用首次成功的状态码和回执。使用 `PATCH fields` 时，未传字段保持原值，显式 `null` 只清除可空字段，集合字段整体替换。内部 ID 使用 UUID 字符串，时间返回 UTC ISO 8601 字符串，修订号为非负整数。分页列表返回 `{items, nextCursor}`，页末 `nextCursor=null`，`limit` 默认 25、最大 100。稳定游标绑定筛选条件，权限与对象类型过滤在关键词匹配、分页和计数前应用。缺失译文使用显式状态。

## 05.0 前后端共用契约

本节文件为已定稿范围的传输权威。实施方案定义业务行为，本文其余章节提供路径索引和时序。文件中的 `definitions` 保存 JSON Schema，`x-operations` 按操作绑定 HTTP 路径、规范化请求和各状态码的响应；`x-examples` 中的 `given`、`request`、`response`、`assertions` 同时供前端夹具和服务端集成验收使用；`x-rejections` 定义必须被 Schema 拒绝的形状。各文件的 `$id` 用于离线解析引用。

样例请求对象的 `path`、`query`、`headers`、`body` 为规范化值。实际 HTTP 的数组查询使用重复参数，例如 `extraLocales=ja&extraLocales=fr`。参数省略表示采用接口默认。Schema 允许空数组时，单个空值（如 `extraLocales=`）表示显式清空；空值与非空值混传、重复标量参数返回 `MALFORMED_REQUEST`。前端与后端均按该约定转换，Schema 检验转换后的类型。样例仅记录有约束的请求头，名称用小写；Cookie 或授权初态由 `given` 指定。`204` 的样例用 `body:null` 表示无消息体。

前端拦截按操作与样例注入响应，后端用同样请求和数据条件复跑。`x-scenarios` 编排单样例和跨接口步骤。`partialBody` 只声明该步要断言的字段，响应整体仍遵循操作 Schema。样例存在 `forbiddenValues` 时，在完整响应内检查这些名称或标识均未出现。同一版本的 Schema 用于夹具、传输类型及路由校验，OpenAPI 由已接通的路由与共用定义生成。启动各开发批次之前，补齐该批尚未覆盖的接口形状和正反样例。样例结构校验、浏览器交互和真库业务断言分别记录结果。

### 05.1.1 管理端读模型补充

- 草稿 `localeActions` 的各项为 `{locale, actions}`。译文项为 `{locale, fields, translationRevision, basedOnSourceRevision, status}`，状态取 `draft`、`reviewed`、`rejected` 或 `needs-review`。有语言区授权但尚无译文时省略该译文项，界面按缺译和预期修订 `0` 处理。仅共享事实的记录返回 `sourceLocale=null`、`sourceRevision=0`、`translations=[]` 和 `localeActions=[]`。目录状态 `catalogStatus` 取 `draft`、`verified` 或 `retired`。
- `referenceSummaries` 按字段返回 `{field, items}`。授权项目含 `id`、`displayName`、适用时的 `referenceVersionId` 和 `state`（`available` 或 `unavailable`）。无读取权限的项只用 `{state:"restricted"}`。若字段含被隐藏的对象，`fields` 中整个关联字段省略，前端只读展示关联摘要。选择结果采用字段规格要求的稳定 ID 或确切版本。
- 管理列表和选择器按账号主语言返回名称。当前语种无可显示名称时 `displayName=null`，稳定编码可用时另返 `code`。与用户查看的明确授权语种相关的预览和正文接口使用本次请求语种。
- `publication-state.allowedOperations` 取当前允许的 `publish`、`withdraw`、`pause`、`restore`、`revoke-version` 的子集。版本摘要再按确切版本授权返回操作，导出语种通过 `exportLocales` 返回。目录对象的 `publication-state` 返回 `kind=catalog` 和共享公开修订号，生效指针、暂停和待审均为空。目录历史从版本接口返回获准审计的已核验版本，只提供确切版本撤销。发布节点的 `kind=node`。候审 `reviewSummary` 提供整体核验状态 `verified` 或 `blocked`，可见明细按语言权限过滤。
- 导入 `status` 取 `previewed` 或 `applied`。变更项为 `{rowId, action, entityType, externalId, targetId?, changedFields}`，`action` 取 `create`、`update` 或 `unchanged`。冲突项为 `{conflictId, rowId, reasonCode, candidates}`，候选含授权的 `{id, displayName}`。`reconciliation` 包含 `createdCount`、`updatedCount`、`unchangedCount`、`mappedCount`、`deferredCount`。应用发生 `409` 时，在同一批次创建新预览并由用户复核；最终用批次 `GET` 核对状态和计数。

普通地区和地点更新与归属变更各有独立请求分支，由同一路由一次校验。普通分支拒绝归属键，归属分支拒绝混入普通字段。服务还须根据目标已有类型校验可修改字段。请求形状无效返回 `400 MALFORMED_REQUEST`，记录类型、已核验配置或父链规则不满足时返回 `422 VALIDATION_FAILED`。国家配置仍用普通分支保存，核验用国家配置接口。 [完整 PATCH 契约](contracts/v1/relocation.schema.json) · [国家配置契约](contracts/v1/country-configuration.schema.json)

### 05.1.2 发布命令、候选与覆盖条件

引用标签校验目标读取、对应语种和所关联对象的权限。直接引用按选定确切版本读取，普通身份关联走当前获准名称。没有请求语种的名称时给缺译状态，可显示获准编码。已撤销与停用后不可用的标签标记不可用，不另选版本。越权项不带 ID、编码或名称。客户端仅消费与编辑草稿修订匹配的响应；本轮新关系先保存后读取。

候选 `snapshot` 区分草稿、恢复来源和冻结申请。指定获准语种时 `preview` 输出结构化正文及引用。省略语种则 `preview=null`，仍可按申请权限读取摘要。显式请求无权语言返回 `403`。冻结申请保持当时的内容和规则组。历史访问校验按实施方案第 02.1 节。 [归属变更与授权](全球旅游后台首版实施方案.md#021-归属变更与授权)

授权正文的 `preview.geographicPath` 与生效详情的 `geographicPath` 使用同一字段结构，由根至直接父级排列，省略对象自己。根对象返回空数组。名称可用时含节点 ID、名称版本及请求语种名称。缺译时不跨语种填充。受限节点仅返回占位状态，连续占位按原顺序保留。草稿、恢复、冻结和当前父链各自取值按实施方案第 08.1 节。恢复须通过源历史版本的现行读取授权。 [父链 Schema](contracts/v1/geographic-path.schema.json)

发布、审批、撤下、恢复、紧急处理和导入应用写请求带 `Idempotency-Key`。以操作者、动作、目标和键确定作用域，保存请求摘要。同键同请求重新鉴权后返回原操作回执，同键不同请求返回冲突。回执含 `id`, `status`, `processedAt`。刷新当前状态使用 `publication-state`。发布状态取 `unpublished`、`published`、`paused`、`withdrawn`，语种或依赖不可读时按 05.2 独立判断。申请状态取 `pending`、`approved`、`rejected`、`conflicted`。

审批命令先核对调用方条件与所读申请的预期条件。调用方传旧修订号或错误预期条件，返回 `409 REVISION_CONFLICT` 并保留待审位。条件与申请一致，但数据库实际公开状态或依赖已经变化并使候审版失效时，在事务内提交 `conflicted`、审计与幂等回执，释放待审位并保留生效指针。该决策记录由 `POST /decisions` 返回 `201`，回执的 `status=conflicted`，附授权可见原因。相同命令重试按原回执展示冲突。

影响预检先校验 `records.read`。普通撤下预检要求目标范围的 `publication.submit`，已有待审撤下时也允许该范围的 `publication.review` 进行复核。暂停或撤销预检要求 `publication.restrict`。目标不可见返回 `404`，有读权而无操作权返回 `403`。影响结果按实施方案第 08.2.1 节计算。只有普通撤下能被公开引用阻断。受限影响响应省略对象身份、数量及版本。撤销针对传入的确切版本，写入前在事务内重新核验依赖，提交后返回回执。 [影响和限制契约](contracts/v1/publication-dependencies.schema.json) · [引用关系决策](全球旅游后台首版实施方案.md#0821-引用关系与公开结果)

发布和恢复申请用 `optionalFieldKeys`、`extraLocales` 表达可见候审选择。预检未传选择时，由服务端返回默认选择。中英文由服务端加入。已有的不可见扩展语种在满足发布资格时保留。`canSubmit` 由完整资格判断生成，权限过滤后的 `issues` 可以为空。实际移除扩展语种时返回授权清单、受限移除标记和绑定候选的 `localeRemovalAcknowledgement`，显式确认后回传。候选或移除结果变化时返回 `REVISION_CONFLICT` 并重新预检。批准有移除的冻结申请时，独立确认其影响，缺确认返回 `422 VALIDATION_FAILED`。因归属双侧权限不足的批准按访问规则返回 `403` 或 `404`，申请保持原状态。权限仍然具备但冻结父链或生效条件已变时，按本节的 `conflicted` 回执关闭申请。

管理行政树查询省略 `parentId` 时返回各个授权范围内的首层可读节点。仅有区级授权的账号可直接从该区展开。祖先路径的名称和其他分支按实际读权限返回。已知 ID 也须重新验权。

覆盖维护、走查和检查仅走管理接口。步骤的 `applicability` 可含 `documentIssuerIds`、`travelPurposeCodes`、`transitAreaIds`、`travelDateFrom`、`travelDateUntil`。多个已配置条件同时匹配，多值条件任一匹配，日期边界包含当天。空条件对象表示普遍适用。缺少用于匹配的输入时应标记待复核。地区与证件签发地从地理查询选择，旅行目的来自 `groupCode=travel-purpose` 的字典，出发市场语种取已核验国家配置。走查绑定覆盖修订；影响关键指引的变动触发重新走查，未通过时保留 `needs-review` 及原因。走查按钮取覆盖结果的 `allowedActions`。

首次发布的示例请求中，`targetId` 来自已加载的内部 ID。所选可选字段、语种及依赖的实际内容由服务端按草稿修订号读取。

```json
{
  "targetId": "00000000-0000-4000-8000-000000000017",
  "operation": "publish",
  "draftRevision": 3,
  "expectedActiveVersionId": null,
  "expectedVisibilityRevision": 0,
  "optionalFieldKeys": [],
  "extraLocales": []
}
```

## 05.2 旅客端读取接口

客户端前端依据本节完成页面与夹具验收。公开路由由第四段客户端服务实现并启用，管理后台 M4 仅提供内部发布读模型与授权预览。

| 客户端服务公开接口 | 请求 | 成功响应 |
| --- | --- | --- |
| `GET /api/published-nodes` | 必填 `language`，可按 `query`, `areaId`, `type`, `cursor`, `limit` 查询 | 分页项含 `id`, `versionId`, `language`, `displayName`, `type`，仅返回请求语种中当前可公开的条目。 |
| `GET /api/published-nodes/{id}` | 必填 `language` | 公开详情包括 `resolvedRules` 和按 Schema 展开的获准内容块。 [公开详情与规则 Schema](contracts/v1/resolved-rules.schema.json) |
| `GET /api/published-nodes/{id}/publication-media/{mediaVersionId}` | `language`, `versionId`，由详情返回 | 重查当前生效版、对该确切媒体版本的引用、许可及版本限制。均有效时返回媒体内容。 |

公开详情的字段和展示块按 `PublicEffectiveDetail` 白名单序列化，省略未获准公开的可选字段。同一馆区的多个说明、展览或史料保留各自 ID 与确切版本。`resolvedRules` 按 `power-supply` 与 `power-plug` 分组展示当前结果。采用来源、版本、区间、缺译和不可用的形状见 Schema；适用区间起点包含、结束时间不包含。规则详情不公开时返回无来源信息的不可用状态。管理预览使用同一业务解析后再裁剪账户权限，历史读取使用已冻结的规则结果。 [规则样例](contracts/v1/resolved-rules.schema.json)

## 05.3 HTTP 状态与错误响应

| HTTP 响应 | 稳定错误码 | 调用方处理 |
| --- | --- | --- |
| `400` | `MALFORMED_REQUEST` | 检查请求类型、格式、必传参数及游标。 |
| `401` | `INVALID_CREDENTIALS`、`SESSION_INVALID` | 凭据失败给出统一提示，会话失效引导重新登录。 |
| `403` | `ACTION_FORBIDDEN`、`CSRF_INVALID` | 显示无权操作或刷新会话令牌后重试。错误只保留可授权的信息。 |
| `404` | `RECORD_NOT_FOUND`、`PUBLISHED_CONTENT_UNAVAILABLE`、`PUBLISHED_LANGUAGE_UNAVAILABLE`、`COUNTRY_CONFIGURATION_UNAVAILABLE` | 公开对象未生效、暂停或撤下时返回内容不可用。当前对象仍有其它公开语种时，语种不可用错误另带 `availableLocales`。获准读取但国家配置未核验时返回配置不可用。 |
| `409` | `REVISION_CONFLICT`、`PENDING_OPERATION_EXISTS`、`WITHDRAWAL_BLOCKED`、`IDEMPOTENCY_CONFLICT`、`LAST_ADMIN_REQUIRED`、`RELOCATION_BLOCKED` | 刷新相关状态，保留获准编辑的本地草稿。归属受阻时先处理公开依赖。停用或撤权前保留至少一位可用的系统根人员管理员。 |
| `413`、`415` | `FILE_TOO_LARGE`、`UNSUPPORTED_MEDIA_TYPE` | 按用途提示允许的大小及文件类型。 |
| `422` | `INVALID_PRIMARY_LOCALE`、`VALIDATION_FAILED` | 按字段展示缺译、引用失效、来源未核等校验问题。 |
| `429` | `RATE_LIMITED` | 按 `Retry-After` 提示可重试时间。 |
| `500` | `INTERNAL_ERROR` | 使用 `requestId` 定位失败。 |
| `503` | `SERVICE_NOT_READY` | 健康检查返回服务未就绪，待数据库连接和当前迁移均可用后重试。 |

错误体使用 `code`、`requestId` 和可选的 `issues`。问题项为 `{field, code, locale?, referenceId?}`，只包含有权读取的明细。管理对象对当前账号不可见时返回 `RECORD_NOT_FOUND`，错误体不含 `issues`。有对象读取权限而缺少具体动作时返回 `ACTION_FORBIDDEN`。界面按主语言翻译错误码。 [HTTP 状态语义](https://www.rfc-editor.org/rfc/rfc9110.html#name-status-codes)
